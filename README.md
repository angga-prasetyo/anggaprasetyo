# Angga Prasetyo

Personal Web describes who Angga Prasetyo is.

---

## Tech Stack

- **Frontend:** React, Vite, Shadcn (Radix UI), Tailwind, Rive
- **Frontend State Management:** Zustand
- **Frontend Testing Libary:** React Testing Library, Playwright

---

## Getting Started

```bash
# 1. Clone
git clone https://github.com/angga-prasetyo/anggaprasetyo.git
cd anggaprasetyo

# 2. Install dependencies
pnpm install

# 3. Run UI: development environment
pnpm start

# 4. Run UI: production environment
pnpm build
pnpm serve

# 5. Run ESLint
pnpm lint

# 6. Run Unit Tests
pnpm coverage

# 7. Run E2E Tests
pnpm e2e

# 8. Run ESLint, Unit Tests, and E2E Tests
pnpm test
```

> Requires: Node.js v22.17.1+
